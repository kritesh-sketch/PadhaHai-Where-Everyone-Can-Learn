# PadhaHai: Where Everyone Can Learn

Free online learning platform for learners, instructors and administrators.

## Structure
- apps/web        Next.js app (frontend + backend)
- apps/worker     Background jobs (later)
- packages/       Shared database, UI, validation, types, config
- design/         Wireframes, mockups, brand
- docs/           Requirements, architecture, testing, FYP report
- business/       Startup material
- infra/          Deployment and environments

## Setup
    pnpm install
    pnpm dev
